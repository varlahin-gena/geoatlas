# Аномалии

Фоновый движок ищет подозрительные паттерны в трафике и показывает их на карте и на странице **`/anomalies`**.

Доступ к списку / ack / assign — любой залогиненный (**administrator**, **operator**, **dashboard**). Статус движка (`GET /api/anomalies/status`) — Bearer ≥ **ops** или administrator.

Сканер работает только при наличии **сетей предприятия** (иначе `no_enterprise_nets`).

Срабатывания, ack, назначения и подавления живут в ClickHouse (`anomaly_events`, `anomaly_acks`, `anomaly_assignments`, `anomaly_suppressions`). Пороги со страницы движка — в `/app/data/anomaly_settings.json`. Журнал уезжает в бэкап ClickHouse, JSON — в соседний `*.auth.tgz`. См. [резервное копирование](operations.md#резервное-копирование-clickhouse).

## Типы

| Код | Смысл (UI) | Severity |
|-----|--------|----------|
| `port_scan` | Заблокированное сканирование портов | high |
| `horizontal_scan` | Обход подсети (старые алерты, детектор снят) | high |
| `blocked_surge` | Резкий рост блокировок | warn / high |
| `byte_surge` | Резкий рост исходящего или входящего трафика | warn / high |
| `beaconing` | Регулярные короткие сессии к новому или отмеченному адресу | warn / high |
| `lateral_fanout` | Обход хостов предприятия | high |
| `new_country_dst` | Новая страна | warn |
| `rep_new_peer` | Контакт с отмеченным адресом | high |
| `hunt_threshold` | Охота превысила порог | — |

На карте — полоска/баннер со ссылкой на `/anomalies`. На странице аномалий:

- **«Связи»** — рёбра из `GET /api/events` по `src`/map.q (агрегированные peers, не сырой PCAP);
- **«Разбор»** — страница [`/investigate?alert=<fingerprint>`](ui.md): шапка алерта, peers, ack/assign, клиентский CSV peers, сохранение query как search template, deep-link на карту (без встраивания MapLibre).

Fingerprint в URL даёт ссылку на алерт; отдельного хранилища кейсов нет.

## Детекторы (v2.3+)

Окна сканирования и пороги зависят от [профиля производительности](operations.md#профили-производительности) (`install-profile.json`). Сети предприятия обязательны для всех детекторов.

| Код | Окно | Логика (кратко) |
|-----|------|-----------------|
| `port_scan` | 5 мин | Уникальные порты назначения среди блокировок и отказов. Частные источники входят всегда |
| `lateral_fanout` | 15 мин | Много адресов внутри сетей предприятия. Источник может быть снаружи. Успешные соединения и отказы. Адреса из списка исключений не попадают в сигнал |
| `blocked_surge` | 15 мин | Блокировок стало кратно больше. В карточке главные адреса. «Важно», если один адрес дал не меньше половины |
| `byte_surge` | 1 ч | Объём с адреса в сети и объём на адрес в сети против прошлого часа. Второй участник в карточке. Почти пустой прошлый час не даёт сигнала. Своя передача — одна карточка |
| `beaconing` | 24 ч | Ровная связь с небольшим объёмом, и внешний адрес уже отмечен или раньше не встречался. В окне обучения остаётся только уже отмеченный адрес |
| `new_country_dst` | 1 ч vs 7 дн | Адрес из сети предприятия пошёл в страну, куда он не ходил последние 7 дней. В окне обучения проверка молчит |
| `rep_new_peer` | 15 мин | Связь с адресом из списка отмеченных, а не самый крупный поток. Такой пары не было около 7 дней |

`horizontal_scan` новым сканом не пишется. Старые строки в журнале остаются.

### Пороги новых детекторов по профилю

| Профиль | byte_surge ratio / abs min | beacon min ч / max avg bytes | lateral hosts / events |
|---------|----------------------------|------------------------------|------------------------|
| `tiny` | 5× / 50 MB | 8 / 200 KB | 15 / 30 |
| `small` | 5× / 80 MB | 10 / 250 KB | 20 / 40 |
| `medium` | 5× / 100 MB | 10 / 300 KB | 25 / 50 |
| `large` | 4× / 200 MB | 12 / 400 KB | 40 / 80 |
| `xlarge` | 4× / 400 MB | 14 / 500 KB | 50 / 100 |

`ByteSurgeFloor` и `BeaconMinRegularity` (0.55–0.6) задают нижнюю планку шума и минимальную «ровность» часовых интервалов; в env не выносятся — только через профиль или UI overrides.

### Редактирование порогов (UI)

Администратор на **`/anomalies/engine`** (страница **Движок аномалий**) может переопределить чувствительность проверок (`GET`/`PUT /api/anomalies/settings`). Значения пишутся в `/app/data/anomaly_settings.json` и подхватываются без рестарта; сброс возвращает defaults профиля. Подписи и группировка полей — в UI (справка по каждому порогу).

### Окно обучения

Пока данные моложе `ANOMALY_LEARNING_DAYS` (в UI — «дней на привыкание»), «Новая страна» не ищется. «Регулярные короткие сессии» в это время показываются только для уже отмеченного внешнего адреса. Остальные проверки работают.

Список «Источники без обхода хостов» на странице движка — адреса, которые не считаются обходом хостов в сети. У каждой проверки отдельно есть исключение тем же конструктором, что и поиск на карте: совпавшие строки журнала в эту проверку не входят. Старое поле `include_private` в файле настроек сохранено и на сканирование портов больше не влияет: адреса локальной сети входят всегда.

## Разбор алерта

Маршрут **`/investigate?alert=<fingerprint>`** — страница разбора алерта: без отдельного хранилища кейсов на backend.

| Возможность | Как |
|-------------|-----|
| Открыть | Кнопка «Разбор» на `/anomalies` или прямая ссылка с fingerprint |
| Контекст | Тип, severity, src/dst, окно, счётчик событий, статус ack |
| Связи (peers) | `GET /api/events` по query алерта (агрегированные рёбра, как на карте) |
| Ack / assign | Те же `POST /api/anomalies/{fingerprint}/ack` и `…/assign` |
| CSV peers | Клиентская выгрузка из загруженных peers |
| Шаблон поиска | Сохранение query алерта в личные search templates |
| Карта | Deep-link «На карте» (MapLibre на страницу разбора не встраивается) |

Поиск алерта — за последние **7 суток** (`include_acked=1`, limit 200). Если fingerprint не найден, показывается предупреждение.

Роли: **administrator**, **operator**, **dashboard** (как `/anomalies`). Подробнее о страницах: [ui.md](ui.md).

## Включение и интервал

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `ANOMALY_ENABLED` | `true` | Выключатель движка |
| `ANOMALY_SCAN_INTERVAL` | `5m` | Период фонового скана |
| `ANOMALY_INCLUDE_PRIVATE` | `false` | Поле сохранено в настройках. Скан портов частные адреса учитывает всегда |
| `ANOMALY_LEARNING_DAYS` | `3` | Окно обучения |
| `ANOMALY_SUPPRESS_HOURS` | `24` | Не повторять то же срабатывание сразу |

Полный список env: [configuration.md](configuration.md#репутация-и-аномалии).

## Ack и назначение

- **Ack** — `POST /api/anomalies/{fingerprint}/ack` (сессия login): событие отмечено обработанным; могут заполниться `ack_by` / `assigned_to`.
- **Assign** — `POST /api/anomalies/{fingerprint}/assign`: исполнитель из `GET /api/users/directory`.
- В UI на `/anomalies` — список, переключатель «Показывать закрытые», назначение ответственного.

Контракт: [`openapi.yaml`](../openapi.yaml). Роли: [ui.md — доступ](ui.md#роли-и-доступ).
