# Интернационализация (i18n)

Operator UI построен вокруг каркаса [i18next](https://www.i18next.com/) + `react-i18next` (`frontend/src/i18n/`).

- Локали: `frontend/src/i18n/locales/ru.json` (default) и `en.json` (stub).
- `document.documentElement.lang` выставляется из активной локали при старте и смене языка.
- Часть строк уже на ключах (бренд, skip-link, title входа); остальной UI пока hardcoded на русском и мигрируется в JSON по мере PR.

Добавить ключ: правка обоих locale-файлов + `useTranslation()` / `t('…')` в компоненте. Полный перевод всего SPA не требуется для OpenSSF: критерий — **internationalization** (возможность локализации), не готовые N локалей.

См. также [accessibility.md](accessibility.md), [development.md](development.md).

OpenSSF Silver `internationalization` (SHOULD): **Met** — см. [openssf-silver.md](openssf-silver.md).
